## 1. Flow Architecture & Two Charging Paths

EcoVolt provides two distinct charging operational flows:

```
                      [ Station Detail / Map ]
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       [ Path A: Charge Now ]         [ Path B: Smart Charge ]
         Immediate Start               Optimal Renewable Window
         Current Live Tariff           Dynamic ToU Tariff Discount
                 │                               │
                 │                 ┌─────────────┴─────────────┐
                 │                 ▼                           ▼
                 │        [ Auto-Scheduled Window ]   [ Urgent Override: ]
                 │        12:00 PM – 1:30 PM (85% ☀️)  "I need it now"
                 │        Payoff: Save ₹34.00                  │
                 │                 │                           │
                 └────────┬────────┴───────────────────────────┘
                          ▼
            [ Confirm Booking Screen ]
              • Price-Lock Guarantee (validUntil countdown)
              • Locked ₹/kWh Tariff & Estimated kWh
              • Connector & Vehicle Matching
              • Button Busy State ("Reserving Slot…")
                          │
                          ▼
              [ Toast: "Slot Booked" ]
```

## 2. Screen Specifications

### 2.1 `SmartChargeScreen.tsx` (Optimal Green Window Optimizer)
- **Input Constraints**:
  - Target Energy (kWh) / Battery Charge Target ($80\%$ or $100\%$).
  - Latest departure / "Needed by" deadline (e.g., 3:00 PM, 6:00 PM, Tomorrow 8:00 AM).
- **Optimizer Computation**:
  - Displays top indeterminate `LinearProgress` while calculating the optimal solar/wind window.
- **Payoff Card**:
  - Scheduled Start & End times (e.g. `12:00 PM – 1:30 PM`).
  - Renewable generation mix expected (e.g. `85% Solar Peak`).
  - Expected cost savings in ₹ vs charging immediately (e.g. `Save ₹34.00`).
  - Carbon avoided vs grid-average ($\text{kg CO}_2$).
  - Estimated finish time (*"Done by 1:30 PM · 1h 30m before your 3:00 PM deadline"*).
- **Edge Case #13 (Forecast Confidence)**:
  - Displays ML confidence score (e.g. `74% High Confidence`).
  - If confidence is $<60\%$, displays transparent notice: *"Moderate confidence window · ToU discount may vary slightly"*.
- **Edge Case #8 (Urgent Override)**:
  - Dedicated urgent override button: *"⚡ I need it now — bypass schedule and charge immediately"*.
- **Action**: "Lock Window & Review Booking" $\rightarrow$ opens `ConfirmBookingScreen`.

### 2.2 `ConfirmBookingScreen.tsx` (Price-Lock Reservation)
- **Station & Connector Summary**: Name, provider, address, plug type (e.g. CCS2 60kW), and driver's active EV.
- **Edge Case #17 (Explicit Price-Lock Guarantee)**:
  - Quoted final rate is locked in a distinct card (e.g. `₹6.20/kWh LOCKED`).
  - Live countdown timer derived from `validUntil` (e.g. `Price locked for 29:40`).
- **Cancellation & Grace Window**: Explains that cancellations within 15 minutes of scheduled start release the slot without fee.
- **Booking Creation**:
  - Submits `POST /bookings` with stationId, connectorType, vehicleId, windowStart, windowEnd, priceQuoteId.
  - Primary button shows `busy` state with spinner ("Reserving Slot…").
  - On success: shows feedback toast *"Slot Booked · Your connector is reserved"*.

## 3. Edge Cases Handled

| Edge Case | Solution & UX Behavior |
|---|---|
| **#7 Driver Incentive to Wait** | Plain-language payoff card clearly displays the two rewards: **₹ Saved** (e.g. `Save ₹34`) and **% Renewable Gained** (e.g. `+46% clean energy`). |
| **#8 Urgent Override** | An *"I need it now"* button is prominently accessible at every step to bypass scheduled windows without penalty. |
| **#13 Low-Confidence Forecast** | Displays ML confidence rating honestly; flags low-confidence windows with clear disclaimer. |
| **#17 Mid-Booking Price Fluctuation** | Price is formally **locked** at booking time (`validUntil`); countdown timer reassures driver that the quoted tariff is guaranteed. |
