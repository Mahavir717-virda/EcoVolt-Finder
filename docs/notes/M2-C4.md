## 1. Objectives & Scope

Implement user vehicle management endpoints per `/contracts/openapi.node.yaml` and `/contracts/types.ts`:
1. `GET /vehicles`: Retrieve all vehicles owned by the authenticated user (`req.user.sub`).
2. `POST /vehicles`: Create a vehicle profile with validation and class defaults.
3. `PATCH /vehicles/:id`: Update vehicle fields (model, battery capacity, efficiency, connectors, charge %). Enforces owner scoping.
4. `DELETE /vehicles/:id`: Delete a vehicle profile. Enforces owner scoping.

## 2. Validation Rules & Per-Class Defaults

### 2.1 Sensible Defaults per Vehicle Class (Edge Case #11)
- **Car (`car`):**
  - Default `efficiencyWhKm`: `140.0` Wh/km (e.g. Tata Nexon EV / MG ZS EV standard).
  - Default `batteryKwh`: `40.0` kWh.
  - Default `connectors`: `['ccs2', 'type2_ac']`.
- **Bike (`bike`):**
  - Default `efficiencyWhKm`: `35.0` Wh/km (e.g. Ather 450X / Ola S1 Pro standard).
  - Default `batteryKwh`: `3.7` kWh.
  - Default `connectors`: `['type2_ac', 'three_pin']`.

### 2.2 Numerical & Boundary Validation (Edge Case #24)
- `vehicleClass`: Required enum `['car', 'bike']`.
- `batteryKwh`: Float, strictly $> 0` (e.g. `min(0.5)`). Rejects `0`, negative numbers, NaN.
- `efficiencyWhKm`: Float, strictly $> 0` (e.g. `min(1)`). Rejects `0`, negative numbers, NaN.
- `currentChargePct`: Float, strictly bounded between `0.0` and `100.0` inclusive (`0 <= currentChargePct <= 100`).
- `connectors`: Array of valid `ConnectorType` enum values (`ccs2`, `chademo`, `type2_ac`, `bharat_dc_001`, `bharat_ac_001`, `three_pin`), non-empty array with at least 1 connector.

## 5. Acceptance Criteria & Test Plan

1. `GET /vehicles` returns all vehicles belonging only to `req.user.sub`.
2. `POST /vehicles` with valid inputs creates vehicle and applies defaults if optional fields are omitted.
3. `POST /vehicles` rejects invalid numerics: `batteryKwh <= 0`, `currentChargePct < 0` or `> 100`, `efficiencyWhKm <= 0`, invalid connector enums.
4. `PATCH /vehicles/:id` updates fields and prevents User A from modifying User B's vehicle (`404 Not Found` or `403 Forbidden`).
5. `DELETE /vehicles/:id` deletes the vehicle when owned by user, or returns `404` when trying to delete another user's vehicle.
6. All tests pass in Jest and `tsc` builds cleanly.
