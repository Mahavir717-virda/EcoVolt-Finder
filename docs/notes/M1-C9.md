## 1. Flow Architecture & Session Lifecycle

The active charging screen is the emotional and functional centerpiece for the driver while plugged in. It tracks live power, battery progression, financial expenditure, and grid greenness in real-time.

```
                  [ Slot Confirmed / QR Plug-in ]
                                │
                                ▼
                   [ ActiveSessionScreen (Hero) ]
            ┌───────────────────┴───────────────────┐
            │                                       │
            ▼                                       ▼
  [ Live Telemetry Polling ]               [ Edge Case #18 Check ]
  • Battery %: Current → Target (Linear)   • Connector Offline?
  • ChargingPulse (Single Animated Volt)   • Interrupted handshake?
  • Live Cost Accrual (Locked Price #17)   • Safe state + next step
  • Real-Time Grid Renewable Mix (%)                │
            │                                       ▼
            │                         [ Offline Interruption Banner ]
            │                         • Saved kWh & Billed at locked ₹
            │                         • Finalize & Find Alternative
            │
            ▼
    [ Stop Session Button ]
    • Busy loading state ("Stopping Session…")
    • POST /sessions/:id/stop
            │

   [ Session Completion Summary ]

   • Total ₹ Paid (Locked Rate)
   • Avg Renewable Mix Achieved (%)
   • CO₂ Avoided vs Grid (kg)
   • Actions: "View Green Impact", "Done"
```

## 2. Key Screen Elements & Architecture

### 2.1 Hero Telemetry & Single Animated Element
- **Living Hero Container**: Uses deep dark grid tones (`colors.grid900` / `colors.grid800`) to highlight active charging telemetry.
- **Single `ChargingPulse` Rule**:
  - The **only animated component** on the entire screen is the Volt-teal `ChargingPulse` encircling the live battery status icon.
  - All other gauges, progress bars, and chips remain visually crisp and static to avoid UI distractions and adhere strictly to the "one animated element" design constraint.
  - **Reduced Motion Support**: When `reduceMotion` is enabled, `ChargingPulse` drops its pulsing animation loop and renders as a clean, static volt-accented ring.

### 2.2 Live Determinate Progress Bar (`LinearProgress`)
- Determinate `LinearProgress` visually indicates progress from the starting charge level (e.g. `42%`) up to the user-selected target level (e.g. `80%` or `100%`).
- Clear text annotations specify: *"42% Starting · 68% Now · 80% Target"*.

### 2.3 Financial & Green Metrics (Edge Case #17)
- **Locked-Price Billing (#17)**: Cost is continuously computed as $\text{cost} = \text{deliveredKwh} \times \text{lockedPrice}$.
- A prominent badge confirms: *"🛡️ Locked Rate ₹6.20/kWh"*, ensuring transparency and protecting the driver against mid-session tariff spikes or manager price edits.
- **Live Greenness Chip**: Shows current grid zone renewable share (e.g. `85% Solar Peak`) with standard greenness band coloring and quality provenance badge.

### 2.4 Polling & State Progression (React Query)
- Uses `useQuery` with a 3000ms `refetchInterval` against `/sessions/:id`.
- Standalone / mock fallback provides a deterministic simulation that advances kWh delivered, battery %, cost, and CO₂ avoided every tick so demos and offline runs behave seamlessly.

### 2.5 Stop Action & Completion Summary
- **Stop Session CTA**: High-contrast danger/accent button with `busy` state preventing double taps.
- **Completion Summary Card / View**:
  - Big Space Grotesk numerals (`tabular-nums`).
  - Total kWh delivered (e.g. `18.4 kWh`).
  - Total ₹ paid at locked rate (e.g. `₹114.08`).
  - Average renewable mix achieved (e.g. `82% Clean Power`).
  - Carbon avoided (e.g. `12.6 kg CO₂`).
  - Seamless navigation to Green Impact or Home Map.

## 3. Edge Cases Handled

| Edge Case | Solution & UX Behavior |
|---|---|
| **#17 Mid-Session Tariff Change** | The session strictly bills the price locked at booking (`lockedPrice`). Accrued cost is explicitly labeled with the locked tariff badge. |
| **#18 Connector Goes Offline Mid-Session** | If the connector loses grid handshake or goes offline mid-charge, the screen renders an alert banner: *"Connector Offline / Interrupted"*, guarantees all kWh delivered to that moment are recorded at the locked rate, and guides the driver with concrete next steps (safely unplug, finalize session, or find nearby alternative charger). |
