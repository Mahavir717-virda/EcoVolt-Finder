## 1. Objectives & Scope

Implement charging session lifecycle, live metering calculations, and carbon impact metrics:
1. `POST /sessions/:id/start` — Transition booking to `active` session status, set `startedAt = now()`, verify connector is operational.
2. `POST /sessions/:id/stop` — Stop charging session, compute final energy delivered (kWh), bill strictly at the **locked price snapshot** from the booking, compute average renewable % achieved, and calculate avoided $CO_2$ emissions.
3. `GET /sessions/:id` — Retrieve real-time session status, telemetry, accrued cost, and live greenness.

## 3. Metering, Billing & Emissions Formula

### 3.1 Metering & Energy Delivered ($\text{energyKwh}$)
- In production, energy is pulled from the hardware OCPP meter.
- In demo/testing mode, if `energyKwh` is provided in request body, use it; otherwise compute based on duration and connector power rating:
  $$\text{energyKwh} = \min\left(\text{batteryCapacity}, \frac{\text{durationHours} \cdot \text{powerKw} \cdot 0.90}{1}\right)$$
  (Defaults to a realistic 18.5 kWh if duration is short).

### 3.2 Billing strictly at Locked Price (Edge Case #17)
The final billed cost is computed using the immutable snapshot from `Booking.lockedPrice`:
$$\text{finalPricePerKwh} = \text{booking.lockedPrice.finalPrice}$$
$$\text{totalCost}(\text{₹}) = \text{round}(\text{energyKwh} \cdot \text{finalPricePerKwh}, 2)$$

### 3.3 Renewable Share & $CO_2$ Avoided Calculation
- **$\text{avgRenewablePct}$:** Sampled average of renewable percentage in the station's grid zone across the session duration (e.g. 74.5%).
- **$CO_2$ Avoided vs Grid Baseline:**
  $$\text{baselineIntensity} = 710.0\text{ gCO}_2/\text{kWh} \quad (\text{Indian grid average})$$
  $$\text{sessionIntensity} = \text{baselineIntensity} \cdot \left(1 - \frac{\text{avgRenewablePct}}{100}\right)$$
  $$\text{co2AvoidedKg} = \text{round}\left(\frac{\text{energyKwh} \cdot (\text{baselineIntensity} - \text{sessionIntensity})}{1000}, 2\right)$$

## 4. Key Edge Cases Addressed

- **Edge Case #17 (Always bill the locked price):** Even if the station tariff or manager markup changed during the charge, the driver is guaranteed the price locked at booking creation.
- **Edge Case #18 (Connector goes offline mid-session):** If connector status changes to `'maintenance'` or `'offline'` during an active session, the session status is flagged with a descriptive error message and allows safe closure without overcharging.
- **Guard Against Stopping Already-Stopped Session:** Attempting to stop a `completed` or `failed` session returns HTTP 409/400 to prevent duplicate billing.

## 5. Acceptance Criteria & Test Plan

1. Starting an active session transitions booking to `active`.
2. Duplicate start returns 409 Conflict.
3. Stopping a session calculates energy, bills at the locked price, and returns accurate $CO_2$ avoided.
4. Stopping an already completed session returns an error.
5. All tests pass in Jest and `tsc` builds cleanly.
