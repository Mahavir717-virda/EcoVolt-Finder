## 1. Design System Philosophy & AI-Tell Guardrails

The **Living Grid** design system is tailored specifically for Indian EV mobility and clean energy grids. It is crisp, technical, calm, and WCAG AA accessible.

### Guardrail Checklist:
- ❌ **No warm cream / terracotta palettes**: Uses a cool crisp off-white canvas with faint green undertones (`#F3F6F2`) and pure white surface cards (`#FFFFFF`).
- ❌ **No ALL-CAPS eyebrow labels**: All status badges, categories, and labels are written in clean sentence case (e.g., `Very high renewable`, `Live charging`).
- ❌ **No monospace data numbers**: Numbers use `Space Grotesk` with `fontVariant: ['tabular-nums']` to prevent layout jitter on live updates without monospace aesthetic.
- ❌ **No identical generic grey shadows**: Distinct elevation tokens (`e0` border only, `e1` subtle card elevation with deep green tint, `e2` sheet elevation with large blur).
- ❌ **No arbitrary "→" appended to buttons**: Buttons name the exact action directly (e.g., `Book slot`, `Start charging`, `Sign in`).

### Greenness Scale (6 Stops) & Function Signatures
```ts
export type GreennessBand = 'very_high' | 'high' | 'medium' | 'moderate' | 'low' | 'very_low';

export const greennessScale = {
  veryHigh: '#0E8E4F', // >= 80% (deep emerald)
  high: '#3DAE5F',     // 65-79%
  medium: '#8FB93B',   // 50-64% (yellow-green)
  moderate: '#E0A81E', // 35-49% (amber)
  low: '#E2732B',      // 20-34% (orange)
  veryLow: '#C8442E',  // < 20% (clay red)
};

/**
 * Maps renewable percentage (0..100) to hex color token.
 */
export function greennessColor(pct: number): string;

/**
 * Maps renewable percentage (0..100) to GreennessBand string enum.
 */
export function greennessBand(pct: number): GreennessBand;
```

### Typography Scale
- Display / Heading: **Space Grotesk** (`SpaceGrotesk_600SemiBold`, `SpaceGrotesk_700Bold`)
- Body / UI / Captions: **Manrope** (`Manrope_400Regular`, `Manrope_500Medium`, `Manrope_600SemiBold`, `Manrope_700Bold`)

| Token | Size / Line-Height | Family | Weight | Use Case |
|---|---|---|---|---|
| `display` | 34 / 40 | Space Grotesk | 700 Bold | Big hero numbers ("72%", "₹6.8/kWh") |
| `h1` | 26 / 32 | Space Grotesk | 600 SemiBold | Primary screen headers |
| `h2` | 21 / 28 | Space Grotesk | 600 SemiBold | Section titles |
| `title` | 17 / 24 | Manrope | 700 Bold | Card titles, action headers |
| `body` | 15 / 22 | Manrope | 400 Regular / 500 Medium | Default paragraphs, specs |
| `caption` | 13 / 18 | Manrope | 500 Medium | Supporting descriptions, timestamps |
| `micro` | 11 / 15 | Manrope | 600 SemiBold | Badges, chips, status indicators |

### Spacing, Radii & Elevation
- **Spacing (4-base):** `4, 8, 12, 16, 20, 24, 32, 40`
- **Radii:** `sm: 8`, `md: 12`, `lg: 16`, `xl: 22`, `pill: 999`
- **Elevation:**
  - `e0` (inline): `borderWidth: 1, borderColor: '#DCE5DD'` (no shadow)
  - `e1` (card): `y: 2, blur: 8, rgba(12,26,19,0.06), elevation: 2`
  - `e2` (sheet): `y: 8, blur: 24, rgba(12,26,19,0.12), elevation: 6`

## 3. Primitives Specification (`src/components/primitives/`)

1. **`Text`**:
   - Props: `variant` (`'display' | 'h1' | 'h2' | 'title' | 'body' | 'caption' | 'micro'`), `color`, `tabularNums`, `numberOfLines`, `style`.
2. **`Button`**:
   - Props: `variant` (`'primary' | 'secondary' | 'ghost' | 'danger'`), `label`, `onPress`, `disabled`, `busy`, `leftIcon`, `style`.
   - Behavior: When `busy` is true, displays inline `<Spinner size="small" />` while preserving label text.
3. **`Card`**:
   - Props: `elevation` (`'e0' | 'e1' | 'e2'`), `padding`, `onPress`, `children`, `style`.
4. **`Sheet`**:
   - Bottom sheet / modal container with drag handle, animated entrance, backdrop dismiss, and safe area inset handling.
5. **`Chip` / `Badge`**:
   - Props: `label`, `color`, `backgroundColor`, `variant` (`'subtle' | 'solid' | 'outline'`), `dotColor`, `icon`. Sentence-case text formatting.
6. **`Input`**:
   - Props: `label`, `placeholder`, `value`, `onChangeText`, `error` (text), `helperText`, `secureTextEntry`, `leftElement`, `rightElement`.
7. **`SegmentedControl`**:
   - Props: `options` (`{ label: string; value: T }[]`), `value`, `onChange`. Smooth pill selector indicator.
8. **`ListRow`**:
   - Props: `title`, `subtitle`, `leftElement`, `rightElement`, `onPress`, `showDivider`.
9. **`EmptyState`**:
   - Props: `title`, `message` (action-oriented copy), `icon`, `actionLabel`, `onAction`.
10. **`ErrorState`**:
    - Props: `title`, `message` (exact diagnosis + recovery steps), `retryLabel`, `onRetry`.
11. **`OfflineBanner`**:
    - Props: `visible`, `message` ("Offline · showing cached grid data"), `onRefresh`.

## 4. Loading States Specification (`src/components/feedback/`)

All loading components support a `reduceMotion` accessibility toggle:

1. **`Skeleton`**, **`SkeletonCard`**, **`SkeletonRow`**:
   - Animated linear gradient/opacity shimmer over `#EAF0EA`.
   - Respects `reduceMotion` (transitions to static well background).
2. **`LinearProgress`**:
   - Determinate mode (`progress: 0..1`) for battery charging and route steps.
   - Indeterminate mode (infinite scan bar) for multi-step backend computations.
3. **`Spinner`**:
   - Circular spinner with `sm` (inline button) and `lg` (centered full screen) options.
4. **`ChargingPulse`**:
   - Dedicated volt-teal glowing ring pulse for the active charging telemetry screen. Single instance per screen.
