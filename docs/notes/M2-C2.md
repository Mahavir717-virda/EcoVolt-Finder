## 1. Objectives & Overview

Design and implement the PostgreSQL database schema for **ecoVolt-finder** using Prisma ORM.
This includes:
1. Complete schema definition in `prisma/schema.prisma`.
2. Clean relational modeling with foreign keys, indexes, and constraints.
3. Geo-indexing (lat/lng indexes) for fast proximity queries.
4. Comprehensive seed script (`prisma/seed.ts`) populating:
   - Grid zones (`IN-WE`, `IN-NO`, `IN-SO`).
   - Power providers (`torrent_power`, `guvnl_gb`, `adani_energy`, `tata_power`).
   - Demo users (`driver`, `manager`, `admin`).
   - Operators and charging stations with multi-connector configurations.
   - Published tariffs & pricing rules.
   - Demo vehicles, bookings, and completed/active sessions.

---

## 2. Entity-Relationship (ER) Architecture

```
User (driver / manager / admin)
 ├── Vehicles (1:N)
 ├── Operators (1:N, if role = manager)
 │    └── Stations (1:N)
 │         ├── Connectors (1:N)
 │         │    └── PricingRules (1:1 or 1:N)
 │         ├── Bookings (1:N)
 │         └── Reviews (1:N)
 ├── Bookings (1:N)
 │    └── Session (1:1)
 └── Reviews (1:N)

GridZone
 ├── Stations (1:N via zone_id / station_zone_map)
 ├── Tariffs (1:N)
 └── ForecastCache (1:N)
```

## 3. Relational Table Definitions & Mapping to `/contracts`

### 3.1 `User`
- `id`: String (UUID, primary key)
- `email`: String (unique)
- `passwordHash`: String
- `name`: String
- `role`: Enum `Role` (`driver`, `manager`, `admin`)
- `createdAt`, `updatedAt`: DateTime

### 3.2 `Vehicle` (matches `contracts/types.ts:Vehicle`)
- `id`: String (UUID, primary key)
- `userId`: String (FK -> `User.id`, indexed)
- `vehicleClass`: Enum `VehicleClass` (`car`, `bike`)
- `model`: String? (e.g. "Tata Nexon EV", "Ather 450X")
- `batteryKwh`: Float (e.g. 40.5)
- `efficiencyWhKm`: Float (e.g. 140)
- `connectors`: Array of `ConnectorType` (`ccs2`, `type2_ac`, etc.)
- `currentChargePct`: Float (0-100)
- `createdAt`, `updatedAt`: DateTime

### 3.3 `GridZone` & `StationZoneMap`
- `id`: String (e.g. "IN-WE", "IN-NO", "IN-SO", PK)
- `name`: String (e.g. "Western Region Grid", "Northern Region Grid")
- `state`: String? (e.g. "Gujarat", "Maharashtra")
- `createdAt`, `updatedAt`: DateTime

### 3.4 `Operator`
- `id`: String (UUID, primary key)
- `userId`: String (FK -> `User.id`, owner/manager)
- `name`: String (e.g. "Statiq Gujarat", "Tata Power EZ Charge")
- `contactEmail`: String?
- `createdAt`, `updatedAt`: DateTime

### 3.5 `Station` (matches `contracts/types.ts:StationSummary`)
- `id`: String (UUID, primary key)
- `operatorId`: String (FK -> `Operator.id`, indexed)
- `zoneId`: String (FK -> `GridZone.id`, indexed) — **Edge Case #3**
- `name`: String (e.g. "SG Highway Fast Charger hub")
- `lat`: Float (indexed composite `[lat, lng]` for haversine geo-queries)
- `lng`: Float
- `address`: String
- `provider`: Enum `PowerProvider` (`torrent_power`, `guvnl_gb`, `adani_energy`, `tata_power`, etc.) — **Edge Case #2**
- `isActive`: Boolean (default `true`)
- `createdAt`, `updatedAt`: DateTime

### 3.6 `Connector`
- `id`: String (UUID, primary key)
- `stationId`: String (FK -> `Station.id`, indexed)
- `type`: Enum `ConnectorType` (`ccs2`, `chademo`, `type2_ac`, `bharat_dc_001`, etc.)
- `powerKw`: Float (e.g. 60.0, 22.0, 3.3)
- `totalCount`: Int (e.g. 4)
- `availableCount`: Int (e.g. 3)
- `status`: String (e.g. "available", "maintenance", "offline")
- `createdAt`, `updatedAt`: DateTime

### 3.7 `Tariff` & `PricingRule` (Multi-Provider Pricing Engine Support)
- **`Tariff`** (Provider-level published/modelled base tariff):
  - `id`: String (UUID, PK)
  - `provider`: Enum `PowerProvider`
  - `zoneId`: String (FK -> `GridZone.id`)
  - `baseRate`: Float (₹/kWh, e.g. 13.50)
  - `touSlabs`: Json? (optional time-of-day tariff variations)
  - `effectiveFrom`: DateTime
- **`PricingRule`** (Manager station/connector markup & green discount params):
  - `id`: String (UUID, PK)
  - `stationId`: String (FK -> `Station.id`)
  - `connectorId`: String? (FK -> `Connector.id`, null = applies to all station connectors)
  - `providerMarkup`: Float (₹/kWh, ≥ 0, e.g. 3.50)
  - `enableDynamicDiscount`: Boolean (default `true`)
  - `discountMaxKwh`: Float (maximum discount allowed, e.g. 2.50 ₹/kWh)

### 3.8 `Booking` (matches `contracts/types.ts:Booking`)
- `id`: String (UUID, PK)
- `userId`: String (FK -> `User.id`, indexed)
- `stationId`: String (FK -> `Station.id`, indexed)
- `connectorId`: String (FK -> `Connector.id`)
- `connectorType`: Enum `ConnectorType`
- `vehicleId`: String (FK -> `Vehicle.id`)
- `status`: Enum `SessionStatus` (`reserved`, `scheduled`, `active`, `completed`, `cancelled`, `expired`, `failed`)
- `windowStart`: DateTime
- `windowEnd`: DateTime
- `lockedPrice`: Json (Stores snapshot of `PriceQuote` `{ baseTariff, providerMarkup, touAdjustment, finalPrice, isEstimate, validUntil }`) — **Edge Case #17**
- `createdAt`, `updatedAt`: DateTime

### 3.9 `Session` (matches `contracts/types.ts:Session`)
- `id`: String (UUID, PK)
- `bookingId`: String (unique FK -> `Booking.id`)
- `stationId`: String (FK -> `Station.id`)
- `connectorId`: String (FK -> `Connector.id`)
- `connectorType`: Enum `ConnectorType`
- `vehicleId`: String (FK -> `Vehicle.id`)
- `userId`: String (FK -> `User.id`)
- `status`: Enum `SessionStatus`
- `startedAt`: DateTime?
- `endedAt`: DateTime?
- `energyKwh`: Float? (e.g. 18.4)
- `cost`: Float? (₹ billed strictly at locked price)
- `avgRenewablePct`: Float? (e.g. 74.5)
- `co2AvoidedKg`: Float? (e.g. 12.3)
- `createdAt`, `updatedAt`: DateTime

### 3.10 `ForecastCache` & `Review`
- `ForecastCache`: Caches 24h renewable forecasts per `zoneId` / `stationId`.
- `Review`: Optional ratings & feedback from drivers on charging stations.

## 4. Key Edge Cases Addressed

1. **Edge Case #2 (Different providers & pricing)**: First-class `PowerProvider` enum on `Station` and `Tariff`, combined with `PricingRule` for operator markup.
2. **Edge Case #3 (Greenness per grid zone)**: `Station` has foreign key `zoneId` linking to `GridZone`.
3. **Edge Case #17 (Price changes mid-booking)**: `Booking.lockedPrice` stores an immutable JSON snapshot of `PriceQuote` with `validUntil` and exact rates.
