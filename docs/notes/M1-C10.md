## 1. Flow Architecture & Screen Structure

This module provides two vital post-booking / driver portfolio screens:

```
                     [ Driver Navigation / Profile ]
                                   │
                 ┌─────────────────┴─────────────────┐
                 ▼                                   ▼
      [ BookingsScreen ]                      [ ImpactScreen ]
  • Filter Segmented Control:             • Big Space Grotesk Numerals:
    [ Upcoming | Active | History ]         - Lifetime ₹ Saved vs Sticker
  • List States:                            - Total kg CO₂ Avoided
    - Upcoming with Grace-Window Cancel     - Lifetime kWh & Clean Energy Mix
    - Active with Live Telemetry link       - Equivalent Trees / Clean Km

  • Edge Case #20 (Inviting Empty State)  • Edge Case #20 (First Charge Invite)
```

## 2. Key Screen Elements & Architecture

### 2.1 `BookingsScreen.tsx` (Reservations & History)
- **Segmented Filter Tabs**: `Upcoming` (reserved slots), `Active` (currently charging), `History` (completed/cancelled sessions).
- **Loading State**: Renders `SkeletonRow` placeholders while fetching data.
- **Card Items**:
  - **Station & Provider**: Name, operator, connector type (e.g. CCS2 60kW).
  - **Locked Tariff Badge (Edge Case #17)**: Rate locked at reservation time (`₹6.20/kWh`).
  - **Time Window**: Local IST time format (`12:00 PM – 1:30 PM`).
  - **Grace-Window Cancel Action (Edge Case #23)**:
    - Calculates time until slot start.
    - If within the 15-minute grace window: Allows one-tap cancellation with full refund and instant slot release.
    - Button with `busy` spinner during cancellation.
- **First-Time Empty States (Edge Case #20)**:
  - Inviting messages: *"No upcoming bookings — discover high-renewable charging stations on the map"* with direct button to `Explore` or `SmartCharge`.
  - Never dead-ends the driver.

### 2.2 `ImpactScreen.tsx` (Lifetime Eco Impact Dashboard)
- **Space Grotesk Hero Numerals**:
  - `₹ Saved vs Sticker`: (e.g. `₹412`) — money saved by picking green/ToU windows and true lowest cost routes.
  - `kg CO₂ Avoided`: (e.g. `164.2 kg`) — calculated against fossil-heavy baseline grid emissions.
  - `Avg Renewable %`: (e.g. `78.4%`) — average green power achieved across all charging sessions.
  - `Total Energy`: (e.g. `342.5 kWh`) delivered across completed sessions.
- **Renewable-Share Visual**:
  - Breakdown bar showing energy source composition (Solar, Wind, Hydro, Grid Baseline).
  - Real-world equivalent impact badges (e.g. *"🌲 Equivalent to 8 trees planted"* & *"🚗 1,840 km of zero-carbon driving"*).
- **First-Time Empty State (Edge Case #20)**:
  - If user has 0 sessions: Shows encouraging *"Begin Your Green Journey"* card showing potential annual savings and clean energy rewards.

## 3. Edge Cases Handled

| Edge Case | Solution & UX Behavior |
|---|---|
| **#20 Empty History / No Bookings** | Contextual, inviting empty states with action triggers (*"Find Solar Charging"*, *"Plan Smart Schedule"*) that navigate directly to map or optimizer rather than dead-ending. |
| **#23 Cancellation within Grace Window** | Allows seamless cancellation if within the contract grace window (releases slot, prevents penalties). Explicit confirmation dialogue informs driver that the slot was released without fee. |
