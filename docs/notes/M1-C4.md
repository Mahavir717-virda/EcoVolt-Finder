## 2. Screen Regions

### 2.1 The Map Canvas (`react-native-maps`)
- Renders `MapView` centered on driver coordinates (or selected mock/search origin).
- Custom markers (`GreennessPin`) rendered with dynamic greenness coloring via `greennessColor(renewablePct)`.
- Interactive state: Tapping a pin selects the station, centers map camera, and highlights the corresponding carousel card.
- Recenter floating action button (`FAB`) to quickly snap camera back to driver location.
- Support for "Pick on Map" mode when GPS permissions are denied or when the user wants to inspect distant hubs.

### 2.2 Top Greenness Floating Badge
- Displays real-time grid renewable mix: `"Grid now: NN% renewable · <band>"`.
- Accompanied by a bold `DataQuality` provenance chip (`LIVE` | `CACHED` | `MOCK` | `STALE`).
- Refetch indicator: Progressive/optimistic design — when background polling triggers, an animated volt-teal dot pulses silently without blocking map interaction.

### 2.3 Search & Action Bar
- Search `Input` for keyword filtering (station name, operator, neighborhood).
- Filter trigger button showing an active filter badge counter.
- Clear search icon and quick-reset controls.

### 2.4 Filter Bottom Sheet (`FilterSheet.tsx`)
- Slide-up `Sheet` allowing drivers to refine stations by:
  - **Connector Type**: Multi-select pills (CCS2, Type 2 AC, Bharat DC-001, Bharat AC-001, CHAdeMO, Three Pin).
  - **Minimum Power (kW)**: Threshold buttons (Any, 15 kW+, 30 kW+, 50 kW+, 60 kW+).
  - **Vehicle Class**: `SegmentedControl` (Car vs Bike) feeding efficiency defaults.
  - **Reachable Only**: Toggle switch to hide stations outside estimated remaining battery range.
  - **Sort Order**: Segmented selector between:
    - *True Total Cost* (charging ₹ + travel ₹ — prevents cheaper-farther trap).
    - *Greenest* (renewable %).
    - *Nearest* (distance km).
  - Reset & Apply actions.

### 2.5 Station Cards Carousel & Bottom Card
- Horizontal paging list of `StationCard` elements positioned over the lower map region.
- Displays loading state via `SkeletonCard` during network/query hydration.
- Card metrics:
  - Station name, operator & power provider.
  - Distance (km) & drive duration (mins).
  - Base price (`priceFrom` ₹/kWh) & estimated `trueTotalCost`.
  - Renewable chip with color-coded greenness badge (`renewablePct% · <band>`).
  - Connector summary with real-time available/total count.
  - Unreachable / Incompatible warning indicators where applicable.
  - Direct CTA button $\rightarrow$ navigates to `StationDetailScreen`.

## 3. Data Hooks Architecture

### 3.1 `useLiveGrid()`
- Fetches `/grid/live` via `@tanstack/react-query` with a 60-second stale time and periodic background refetch.
- Returns `{ data: GridSnapshot, isFetching, isLoading, isError, refetch }`.
- Progressive / optimistic: Retains last-known data while refetching.

### 3.2 `useDriverLocation()`
- Handles `expo-location` permission flow:
  1. Requests foreground permission (`Location.requestForegroundPermissionsAsync()`).
  2. If granted: Obtains GPS coordinates (`Location.getCurrentPositionAsync()`).
  3. If denied/unavailable: Transitions seamlessly to fallback mode using default EV hub coordinates (Ahmedabad: `23.0370, 72.5622`) without any dead ends.
- Provides `setManualLocation(coords)` for pick-on-map and search override.

### 3.3 `useNearbyStations()`
- Combines `/stations`, active vehicle profile (or sensible defaults), and driver coordinates.
- Calculates:
  - Haversine distance (km) and travel duration (min).
  - Estimated vehicle range based on `batteryKwh`, `currentChargePct`, and `efficiencyWhKm`.
  - Reachability check: `distanceKm <= remainingRangeKm`.
  - Travel cost: `(distanceKm * efficiencyWhKm / 1000) * avgTariffRate`.
  - True total cost: `chargingCost + travelCost`.
- Evaluates connector compatibility against the driver's vehicle profile.
- Applies user-selected filters and sorts by the chosen criterion.

## 4. Edge Cases & Closing Loopholes

| Edge Case | Solution & Voice |
|---|---|
| **#9 Vehicle can't reach station (Range)** | Station card and pin are greyed out with an explicit warning banner: *"Unreachable · Battery range 32 km · Station is 45 km away"*. If "Reachable only" filter is toggled on, it is excluded from list. |
| **#10 Incompatible connector** | Incompatible connectors are flagged or excluded based on driver's vehicle connector profile. |
| **#12 Grid API down / Mock mode** | Tagged with `DataQuality.MOCK` or `DataQuality.CACHED` in the top badge. UI never misleadingly presents simulated data as certified live grid measurements. |
| **#19 Location permission denied** | Fallback banner appears with guidance: *"Location permission denied · Showing Ahmedabad hub · Tap anywhere on map or search to reposition"*. No dead ends. |
| **#20 No stations / empty state** | Displays actionable `EmptyState`: *"No stations in range — widen your search filters or switch to a 2-wheeler profile"* with a *"Reset Filters"* CTA. |
