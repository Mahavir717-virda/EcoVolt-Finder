## 2. Signature Components Specification

### 2.1 `GreennessGauge` (`components/station/GreennessGauge.tsx`)
- Renders an SVG radial arc using `react-native-svg` colored according to the greenness scale (`greennessColor(renewablePct)`).
- Centered numerals in `SpaceGrotesk_700Bold` (e.g. `85%`) accompanied by human-readable band tag (`Very High Renewable`).
- **Edge Case #4**: Explicitly displays both `renewablePct` (Solar + Wind + Hydro + Biomass) and `carbonFreePct` (which includes Nuclear), preventing term conflation.
- Shows `DataQuality` provenance badge (`LIVE` | `CACHED` | `MOCK` | `STALE`).

### 2.2 `ForecastStrip` (`components/station/ForecastStrip.tsx`)
- Displays 24-hour renewable forecast points in a horizontal interactive timeline / bar chart.
- Highlights the recommended optimal charging window with volt/brand glow.
- **Edge Case #13**: Forecast confidence displayed honestly (e.g. `Confidence: 74%`). Low-confidence hours (<0.60) are visually muted/greyed.

### 2.3 `PriceBreakdown` (`components/station/PriceBreakdown.tsx`)
- Unpacks the tariff equation: `finalPrice = baseTariff + providerMarkup + touAdjustment`.
- Per-connector breakdown with power capacity (kW).
- **Edge Case #14**: When `isEstimate: true`, displays an `"estimate"` pill tag explaining that ToU/base components reflect transparent proxy modeling.

### 2.4 `TrueCostCard` (`components/station/TrueCostCard.tsx`)
- Displays the complete travel-inclusive expense equation: `energyNeededKwh × finalPrice + travelCost = trueTotalCost`.
- **Edge Case #1**: Exposes the cheaper-farther station trap via `vsCheapestSticker` line (e.g., *"₹9 cheaper than Station B once travel is added"*).

## 3. Loading Skeletons & Edge Cases Handled

| Edge Case | Solution & Voice in UI |
|---|---|
| **#1 Cheaper-but-farther station trap** | `TrueCostCard` computes travel cost and ranks by `trueTotalCost`, warning when a lower sticker price costs more overall. |
| **#4 Renewable vs Carbon-Free** | Split metric labels: Renewable (85%) and Carbon-Free (88%), with tooltip explaining nuclear inclusion. |
| **#5 Large-Hydro convention** | Clear methodology subtitle: *"Hydro included in renewable mix per Indian grid dispatch standard"*. |
| **#13 Forecast presented as certainty** | Every forecast point displays confidence rating; low-confidence slots are greyed. |
| **#14 No published ToU tariff** | Transparent modeled proxy labeled with `ESTIMATE` badge. |
