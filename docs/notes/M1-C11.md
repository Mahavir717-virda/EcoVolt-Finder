## 1. Flow Architecture & Screen Structure

The Station Manager experience empowers charging network operators to manage hardware, mitigate demand charges, and dynamically control tariffs:

```
                      [ Manager Portal Navigation ]
                                    │
       ┌────────────────────────────┼────────────────────────────┐
       ▼                            ▼                            ▼
 [ ManagerDashboard ]      [ StationFormScreen ]      [ PricingControlsScreen ]
 • Station list & occupancy • Station Name & Geocode   • Base Tariff (per provider)
 • Today's Revenue (₹)      • Power Provider (DISCOM)  • Service-Provider Markup
 • Renewable Share (%)      • Connectors (Type, kW, #) • Dynamic Green Discount Toggle
 • Demand-Charge Risk Meter • Ownership Check (#22)    • Live 24h Tariff Preview (#2)
 • Live Sessions & Offline                             • Non-negative guard (#24)
```

## 2. Key Screen Elements & Architecture

### 2.1 `ManagerDashboardScreen.tsx` (Operator Cockpit)
- **Top KPI Banners (Space Grotesk)**:
  - **Today's Revenue**: ₹8,420 (calculated from active & completed sessions).
  - **Live Network Occupancy**: 72% across managed plugs.
  - **Live Renewable Share**: 82% solar/wind grid mix.
- **Demand-Charge Risk Meter (Edge Case #16)**:
  - Tracks concurrent charging load against the station's grid transformer sanction (e.g., `112 kW / 150 kW (74% Load)`).
  - Risk states: `Normal (<60%)`, `Moderate (60-80%)`, `Critical Peak (>80%)`.
  - Alert banner nudges: *"Approaching peak demand threshold · SmartCharge nudging upcoming bookings to 2:00 PM"*.
- **Station List Cards**:
  - Provider badge, address, online/offline connector counts, and quick actions (`Edit Station`, `Pricing`, `Sessions`).
- **Live Active Sessions & Connector Status**:
  - Displays active vehicles charging at each plug with power draw.
  - Quick action: **Mark Connector Offline / Online** with safety confirmation.

### 2.2 `StationFormScreen.tsx` (Add & Edit Station)
- **Station Identity**: Name, operator phone, address, and GPS coordinates.
- **Power Provider Selector (Edge Case #2)**:
  - First-class selection: *Torrent Power, GUVNL (Gujarat Urja), Adani Energy, Tata Power, BSES, MSEDCL, Other*.
  - Auto-configures default DISCOM base tariffs and local zone mappings.
- **Connectors Builder**:
  - Add/remove plugs with type (CCS2, Type 2 AC, Bharat DC), rated power (e.g. 60 kW), and count.
  - Form validation: Power kW must be $>0$, total count must be $\ge 1$.
- **Ownership Guard (Edge Case #22)**:
  - Only stations owned by the authenticated manager ID are editable.

### 2.3 `PricingControlsScreen.tsx` (Tariff & Dynamic Discount Engine)
- **Base Tariff Input**: Displays provider default (e.g. ₹5.50/kWh for Torrent), user-editable.
- **Provider Markup (₹/kWh)**:
  - Operator's profit margin.
  - **Edge Case #24 Validation**: Strictly rejects negative values (`markup >= 0`).
- **Dynamic Green Discount Engine**:
  - Toggle to enable/disable automated ToU / green discount (e.g. up to `-₹0.80/kWh` during $>80\%$ solar generation).
- **Live 24-Hour Price Preview (Edge Case #2)**:
  - Interactive hourly visual table/strip displaying `finalPrice = baseTariff + markup + touAdjustment` for every hour of the day.
  - Highlights Solar Peak discounts in green and Evening Peak surcharges in amber.

## 3. Edge Cases Handled

| Edge Case | Solution & UX Behavior |
|---|---|
| **#2 Provider is First-Class** | DISCOM provider selection directly determines default base tariffs and grid zone linkages; tariffs are tailored per provider. |
| **#16 Demand-Charge Risk** | Real-time demand meter alerts operator when total concurrent load approaches transformer peak sanction, preventing expensive grid penalties. |
| **#22 Manager Ownership Guard** | Validates station owner ID before edit; non-owned stations are view-only with clear permission guard. |
| **#24 Bad Numeric Inputs** | Form validation blocks negative markups, zero/negative base tariffs, and invalid kW ratings with immediate helper errors. |
