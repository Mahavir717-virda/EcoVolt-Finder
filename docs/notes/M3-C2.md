## 1. `GridSource` Interface

```python
class GridSource(Protocol):
    async def fetch(self, zone_id: str) -> GridSnapshot: ...
    @property
    def name(self) -> str: ...
```

Every source (`ElectricityMapsClient`, `IndiaAtlasClient`, `MockGenerator`) implements
this protocol. The resolver picks which source to call — sources never know about each other.

## 2. Electricity Maps Client (`electricity_maps.py`)

**Base URL:** `https://api.electricitymap.org/v3`
**Auth:** `auth-token: <ELECTRICITY_MAPS_TOKEN>` request header

### Endpoints used

| Endpoint | Purpose |
|---|---|
| `GET /power-breakdown/latest?zone=<zoneId>` | Fuel-mix breakdown (MW) + marginal carbon intensity |
| `GET /carbon-intensity/latest?zone=<zoneId>` | Life-cycle carbon intensity (gCO₂eq/kWh) — fallback if breakdown unavailable |

### Zone mapping

| Our `zoneId` | Electricity Maps zone |
|---|---|
| `IN` | `IN` (national) |
| `IN-WE` | `IN-WE` (Western — Gujarat, Maharashtra, Goa) |
| `IN-SO` | `IN-SO` (Southern — Tamil Nadu, Karnataka, AP, Kerala) |
| `IN-NO` | `IN-NO` (Northern — UP, Delhi, Haryana, Punjab, HP, J&K) |
| `IN-EA` | `IN-EA` (Eastern — WB, Odisha, Bihar, Jharkhand) |
| `IN-NE` | `IN-NE` (North-Eastern — Assam etc.) |
| unknown | falls back to `IN` (national) |

### Parsing → `GridSnapshot`

```
renewablePct  = (solar + wind + hydro + biomass + geothermal) / total_mw * 100
carbonFreePct = renewablePct_mw + nuclear_mw) / total_mw * 100
carbonIntensity = from the API's carbonIntensity field (gCO₂eq/kWh)
band          = computed from renewablePct thresholds
quality       = "live"
asOfAgeSec    = int(now_utc - datetime of the reading)
```

`unknown` generation is **never included in numerators** — included in breakdown dict but excluded from renewable/carbonFree pct. `unclassifiedPct = unknown_mw / total * 100`.

### Retry / backoff

- 2 attempts, exponential backoff: 0.5 s, 1.0 s
- Timeout: 5 s per request
- On any exception (`httpx.HTTPError`, timeout, 4xx/5xx): propagate `IngestionError` up to resolver
- The resolver — not the client — decides what to do next

## 3. India Energy Atlas / Grid-India (`india_atlas.py`)

**Status: STUB — no clean public API found.**

Grid-India (the national grid operator) does not currently offer a public REST API with
real-time fuel-mix data accessible without an enterprise agreement. The India Energy Atlas
portal provides downloadable CSVs, not a live endpoint.

**What the stub does:**
- Raises `IngestionError("india_atlas: no public API available")` unconditionally
- Documents the correct future endpoint when available
- Is positioned in the resolver's `_SOURCES` list after Electricity Maps so it could be
  promoted to primary in a future chunk without router changes

**When a real endpoint is available**, the implementation will use:
```
GET https://grid-india.in/api/v1/state-wise-generation
```
...but as of 2026 no open-access token-based API was confirmed.

## 4. Mock Generator (`mock_generator.py`)

Models Indian grid patterns deterministically using `random.Random(seed)`.

### Indian grid patterns encoded

| Pattern | Implementation |
|---|---|
| **Solar midday peak** | `solar_mw` is a cosine curve peaking at hour 13 IST (08:30 UTC), zero before 06:00 / after 19:00 IST |
| **Wind stronger at night** | `wind_mw` is higher 20:00–06:00 IST, lower midday; also zone-biased (south coast stronger) |
| **Coal as backbone** | Coal never below 35% of total capacity |
| **Nuclear steady** | ~5–8% stable throughout the day |
| **Hydro season-aware** | Higher in Jul–Sep (monsoon), lower Mar–May (pre-monsoon) |
| **Zone differentiation** | `IN-WE`: solar-heavy; `IN-SO`: wind-heavy; `IN-NE`: hydro-heavy; `IN-NO`: coal-heavy |
| **Seasonal shift** | Month affects solar/wind/hydro amplitude by ±20% |

### Reproducibility

`MockGenerator(seed=42)` always produces the same output for the same `(zone_id, utc_hour)`.
Different zones get deterministic but distinct breakdowns.
`seed` is taken from `settings.mock_seed`.

### Output quality tag

Always `"mock"`. `asOfAgeSec = 0` (mock data is "always fresh").

## 5. Resolver (`resolver.py`)

### Resolution order

```
GRID_MODE=live:
  1. ElectricityMaps.fetch()
  2. On IngestionError → raise HTTPException(503, "grid API unavailable")

GRID_MODE=mock:
  1. MockGenerator.fetch()  ← always succeeds

GRID_MODE=hybrid (default):
  1. ElectricityMaps.fetch()           → tag live, store in cache
  2. On IngestionError → cache.get()   → tag cached (or stale if TTL×2 exceeded)
  3. On cache miss / stale expiry      → MockGenerator.fetch() → tag mock
```

### Cache

```python
_cache: dict[str, tuple[GridSnapshot, datetime]]  # zone_id → (snapshot, fetched_at_utc)
```

- TTL: `settings.grid_cache_ttl_sec` (default 300 s = 5 min)
- `quality = "cached"` if age ≤ TTL × 2
- `quality = "stale"` if age > TTL × 2 (but still returned in hybrid)
- Cache is module-level in-process dict — no Redis needed for M3-C2

### Quality tag lifecycle

| Scenario | quality | asOfAgeSec |
|---|---|---|
| Fresh from Electricity Maps | `live` | seconds since API reading |
| Served from cache, within TTL×2 | `cached` | seconds since original fetch |
| Served from cache, beyond TTL×2 | `stale` | seconds since original fetch |
| MockGenerator returned | `mock` | 0 |

### Error handling

- `IngestionError(source, msg, original_exc)` is raised by sources only
- Resolver catches it, logs it with `structlog`, and continues the chain
- Router gets back a valid `GridSnapshot` in all cases under `hybrid`/`mock` mode
- Under `live` mode, router propagates `HTTPException(503)` to the caller

## 6. Acceptance Criteria (M3-C2)

- [ ] `GRID_MODE=mock` → `/grid/live` returns believable India-shaped data tagged `mock`
- [ ] `GRID_MODE=hybrid` with forced API error → falls back to mock, tags it `mock`
- [ ] `GRID_MODE=hybrid` with valid cache → serves it tagged `cached`
- [ ] `renewablePct ≠ carbonFreePct` when nuclear is non-zero (tested)
- [ ] `unknown` key in breakdown never contributes to renewablePct (tested)
- [ ] All UTC timestamps; `asOfAgeSec` is non-negative
- [ ] `pytest tests/test_ingestion.py` passes (fallback, mock shape, quality tagging)
