## 1. The Core Pricing Formula

Every price quote for ecoVolt-finder is calculated deterministically:

$$\text{finalPrice} = \text{baseTariff}(\text{provider}, \text{zone}) + \text{providerMarkup}(\text{manager}) + \text{touAdjustment}(\text{time}, \text{renewablePct})$$

### Formula Components:
1. **`baseTariff` (₹/kWh):** The DISCOM / Power Provider's rate for the station's grid zone (e.g. Torrent Power = ₹13.50, GUVNL = ₹11.80, Tata Power = ₹12.50, Adani = ₹12.80).
2. **`providerMarkup` (₹/kWh):** The station manager's operational margin / service fee ($\ge 0$). **Negative markups are rejected** via validation (Edge Case #24).
3. **`touAdjustment` (₹/kWh):** 
   - **Published ToU Tariff:** If DISCOM publishes official ToU slabs (e.g. Peak: +₹2.50, Off-Peak: -₹3.00), the published adjustment is applied, and `isEstimate = false`.
   - **Modeled Proxy Discount (Edge Case #14):** If no published ToU tariff exists and dynamic green discount is enabled, we use a transparent modeled proxy:
     $$\text{rawDiscount} = -\left( \frac{\text{renewablePct}}{100} \right) \cdot k \cdot \text{baseTariff}$$
     where $k = 0.25$ (up to 25% discount). When using this modeled proxy, `isEstimate = true`.
4. **Discount Clamping & Price Floor (Edge Case #5 & #14):**
   - The green discount is bounded by `discountMaxKwh` (e.g. max ₹3.00/kWh).
   - $\text{finalPrice}$ is clamped so it **never drops below the legal floor price**:
     $$\text{priceFloor} = 0.60 \cdot \text{baseTariff}$$
     $$\text{finalPrice} = \max(\text{priceFloor}, \text{baseTariff} + \text{providerMarkup} + \text{touAdjustment})$$

## 2. Price Lock Mechanism (`validUntil`) (Edge Case #17)

When `computeQuote` is called:
- `validUntil` is set to $T_{\text{now}} + 30\text{ minutes}$ (ISO 8601 UTC string).
- This creates an immutable, cryptographically verifiable price lock that the driver can book against.
- The active charging session will bill strictly at this locked price even if provider tariffs or manager markups are updated later.

## 3. Endpoints & Module Organization

```
server/src/modules/pricing/
├── pricing.schema.ts      # Zod validation for /pricing/quote query & manager rule update
├── pricing.service.ts     # computeQuote logic, ToU calculator, floor clamping
├── pricing.controller.ts  # Express request handlers
└── pricing.router.ts      # Router mounted at /pricing
```

- **`GET /pricing/quote?stationId&connector&kwh`** $\rightarrow$ returns `PriceQuote`.
- **`GET /pricing/rules/:stationId`** $\rightarrow$ manager reads pricing configuration.
- **`PATCH /pricing/rules/:stationId`** $\rightarrow$ manager updates markup & green discount toggle.

## 4. Key Edge Cases Addressed

- **Edge Case #2 (Different providers, different pricing):** Torrent vs GUVNL vs Adani vs Tata base tariffs resolved from database `tariffs` table.
- **Edge Case #14 (Honest estimate tag):** `isEstimate = true` when ToU adjustment is algorithmic, `false` when using published DISCOM slabs.
- **Edge Case #17 (Locked price guarantee):** `validUntil` timestamp attached to quote; stored as snapshot in booking.
- **Edge Case #24 (Input validation):** Negative markups or negative/zero kWh are strictly rejected.

---

## 5. Acceptance Criteria & Test Plan

1. Quotes for stations with different power providers (Torrent vs GUVNL) reflect different base tariffs.
2. Dynamic green discount reduces price during high renewable generation.
3. Discount never breaches the minimum configured price floor.
4. `isEstimate` flag is accurately tagged based on tariff source.
5. `validUntil` is returned in ISO 8601 UTC format.
6. Comprehensive unit and integration tests pass.
