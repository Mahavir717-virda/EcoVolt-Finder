## 2. Polyline Decoding & Map Polyline Implementation

- **Google Encoded Polyline Algorithm (`src/lib/polyline.ts`)**:
  Decodes string payloads into an array of `{ latitude, longitude }` coordinate objects using the standard 5-decimal variable-length encoding.
- **Map Polyline Rendering**:
  - `Polyline` from `react-native-maps` renders the primary driving route in **Electric Volt Teal (`#0FB8C9`)** with stroke width 4.
  - Secondary path to candidate stations rendered with dashed styling (`strokeDasharray`).
  - Automatic map camera fitting via `mapRef.current.fitToCoordinates([origin, destination], { edgePadding })`.

---

## 3. Vehicle-Aware Travel Cost Model

- Travel cost is calculated dynamically using the active vehicle class:
  - **4-Wheeler (Car)**: $140\text{ Wh/km}$, base travel cost $\approx ₹0.84/\text{km}$.
  - **2-Wheeler (Bike)**: $40\text{ Wh/km}$, base travel cost $\approx ₹0.24/\text{km}$.
- Formula: $\text{Travel Cost} = \frac{\text{Distance (km)} \times \text{Efficiency (Wh/km)}}{1000} \times \text{Average Tariff Rate (₹/kWh)}$.

---

## 4. Head-to-Head Comparison Card (`RouteComparisonCard.tsx`)

Compares:
1. **Selected Station**: User's chosen destination.
2. **Recommended Station**: Algorithmically ranked #1 station factoring greenness, travel distance, and true total cost.
3. **The Trap Exposed Line (`vsCheapestSticker`)**: Shows why nominal low tariffs can result in higher total expense.
4. **Unreachable Override (#9)**: If the selected station is beyond current battery range, clearly flags unreachable status and offers one-tap switch to the reachable alternative.
5. **Urgent Override (#8)**: Allows driver to bypass smart-charge scheduling if immediate charging is required.

## 5. Edge Cases Handled

| Edge Case | Solution & Voice in UI |
|---|---|
| **#1 Cheaper-but-farther station trap** | Clear breakdown showing charging cost vs travel cost with net difference banner. |
| **#8 Driver needs charge NOW** | "I need it now" urgent override option always visible on route preview. |
| **#9 Vehicle can't reach station** | Warning banner: *"Selected station is 9.3 km away (requires 12.4 kWh), exceeding your 8.0 kWh battery level. Switch to recommended station."* |
| **#11 Bike vs Car cost & range difference** | Header displays active profile with efficiency and uses class-specific consumption constants. |
